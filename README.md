# ama-plugin-agent-manager

Agent Manager plugin for `ama-agent-orchestrator`.

Provides the **Agents** console panel: create, edit, and chat with GUI-managed (repo-independent) agents; read-only visibility into mesh (repo-derived) agents; MCP profile assignment via `ama-mcp-registry`; A2A capability connection graph (`agent_connections`) enforced at orchestrator dispatch.

- Parent epic: [ama-shared-context#184](https://github.com/Ask-Me-Anything-dot-work/ama-shared-context/issues/184)
- Plugin host: [ama-agent-orchestrator#264](https://github.com/Ask-Me-Anything-dot-work/ama-agent-orchestrator/issues/264)
- Contract package: `ama-plugin-contract`
